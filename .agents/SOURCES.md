# Skills instaladas para o Estúdio de Historinhas

Estas skills foram copiadas de repositórios oficiais em 18/11/2026. Elas são instruções para agentes, não executam comandos automaticamente.

- Animação e movimento: `emilkowalski/skills`
- Engenharia, testes, performance e segurança: `addyosmani/agent-skills`
- Planejamento e verificação: `obra/superpowers`
- Direção visual de interface: `nextlevelbuilder/ui-ux-pro-max-skill`

O conjunto foi escolhido para apoiar: roteirização por cenas, player Canvas/Three.js, câmera e timing, prototipagem, frontend React, testes de navegador, performance, segurança, planejamento incremental e revisão antes de concluir.

As skills oficiais `prototype` e `review-animations` foram deliberadamente omitidas da pasta portátil porque usam a chave de frontmatter `disable-model-invocation`, específica de outro cliente e rejeitada pelo validador Agent Skills portátil.
